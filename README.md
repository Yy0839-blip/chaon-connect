# Chaon: Your Daily Adventure (73)

차온(CHAON) 앱 — AI Frontend Master Prompt

Create a polished, production-quality mobile-first web app called "차온 (CHAON)".

1. 서비스 개요

차온은 대한민국 경기도 시흥시 대야동에 있는 청소년 공유공간 **"차오름"**을 더 많은 청소년들이 이용하도록 만들기 위한 앱이다.

차오름은 대야동 주민센터 2층에 위치한 청소년 공간이며, 다음과 같은 시설을 가지고 있다.

댄스실

빔프로젝터

대형 거울

복층 1층 / 2층 공간

책

보드게임

청소년들이 자유롭게 머물 수 있는 공간

차온의 가장 중요한 목적은 단순히 정보를 제공하는 것이 아니다.

청소년이 앱을 사용하다가 자연스럽게 차오름에 방문하고, 친구들과 함께 활동하고, 차오름에서 새로운 경험을 만드는 것이 핵심이다.

2. 핵심 타깃

주요 사용자는 대야동에 거주하거나 학교를 다니는 중학교 1~2학년 남녀 청소년이다.

따라서 앱은 공공기관 홈페이지처럼 딱딱하거나 교육 서비스처럼 보이면 안 된다.

청소년들이 실제로 사용하는 SNS, 커뮤니티, 게임 서비스처럼:

재미있고

직관적이며

빠르고

귀엽지만 유치하지 않고

친구에게 보여주고 싶고

매일 다시 들어오고 싶은

느낌을 만들어야 한다.

24. 중요한 UX 원칙

다음 원칙을 반드시 지킨다.

첫 화면에서 사용자가 무엇을 해야 하는지 3초 안에 이해할 수 있어야 한다.

텍스트를 지나치게 많이 사용하지 않는다.

시설 설명보다 "지금 무엇을 할 수 있는가"를 보여준다.

청소년이 실제 SNS를 사용하는 것처럼 자연스럽게 만든다.

모든 화면에서 차오름 방문으로 이어지는 행동을 고려한다.

이벤트와 미션을 자연스럽게 연결한다.

사용자가 앱을 다시 방문할 이유를 만든다.

지나치게 행정적인 디자인을 사용하지 않는다.

청소년의 개인정보와 안전을 최우선으로 고려한다.

앱의 핵심 목적은 앱 사용 자체가 아니라 차오름 이용 활성화라는 점을 잊지 않는다.

26. 최종 디자인 목표

이 앱을 처음 본 중학교 1~2학년 학생이

"이거 뭐야?"

에서 끝나는 것이 아니라,

"오, 여기 가면 뭐 할 수 있지?"

그리고

"친구한테 보내볼까?"

라고 생각하게 만드는 것이 목표다.

차온은 단순한 시설 예약 앱이 아니다.

차오름이라는 오프라인 공간과 청소년을 연결하는 디지털 놀이터처럼 디자인한다.

Build the frontend with realistic mock data, polished interactions, responsive mobile UI, reusable components, and a consistent design system.

Do not create a generic government/community center website.

Make it feel like a real youth-focused product that could actually be launched.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
